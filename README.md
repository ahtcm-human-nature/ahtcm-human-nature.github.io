## 快速开始

### 本地预览

直接用浏览器打开 `index.html` 即可，无需任何服务器环境。

如果想用本地服务器（部分浏览器对 `file://` 下的 localStorage 限制较严）：

```bash
# 任选其一，在项目根目录执行
python -m http.server 8000
npx serve .
```

然后访问 <http://localhost:8000>。

### 部署到 GitHub Pages

1. 在仓库 **Settings → Pages** 中，Source 选择 `Deploy from a branch`，Branch 选择 `main`、目录选择 `/ (root)`
2. 保存后等待 1～2 分钟，页面会给出 `https://<用户名>.github.io/<仓库名>/` 地址
3. 因为入口文件就叫 `index.html` 且位于根目录，无需任何额外配置

> 本项目为纯静态站点，不需要在 Pages 里选择 Jekyll 等主题，直接用 root 即可。

## 目录结构

```
.
├── index.html          # 整个网站（HTML + CSS + JS 全内联，单文件）
├── assets/             # 18 张图片（会徽 + 活动照片）
```

`index.html` 是一个**完全自包含**的单文件：样式、脚本、SVG 图标库全部内联，
唯一的外部依赖是 `assets/` 里的图片。这样部署时只需保证 `assets/` 与 `index.html` 同级即可。

## 图鉴收集 · 殿堂与兑换

站内有 33 个草木与节气的字词散落在正文里，点中任意一个就会落进「自然图鉴」。
集齐全部 33 个之后，会发生三件事：

### 1. 整站进入殿堂模式

全页镀上暖金圣光，顶部落下教堂彩窗的光斑，金色光尘缓缓飘落，导航条也换成金边。
滚动时依然保持——你会一直站在这座殿堂里。切到别的标签页时动画自动暂停省电。

### 2. 圣坛兑换牌

图鉴下方浮出一块牌子，上面是你的**随机兑换码**（形如 `UVR-EJA-K93-TEJ`）与完成时间。
点一下码即可复制。兑换码只存在访客自己的浏览器里，不会上传到任何服务器——
把它发给协会干事，凭码领取活动纪念礼。

> 兑换码字符集已剔除容易认混的 `I O 0 1 2 5 6 8`，方便口头或手写核对。
> 截图转发时他人拿到的是同一份码，所以提醒会员不要外传。

### 3. 成就星图

成就不是一张进度清单，而是一片可以探索的夜空。

- **未解锁的只是一颗暗淡的星**，不写名字、不写条件、连"一共几颗"都不告诉你
- 每颗未亮的星会极轻微地呼吸，像在说"这里好像有什么"，但你得自己试出来
- **你做了某件事，那颗星会亮一下**——你才意识到原来那里有东西
- 亮了之后，鼠标悬停才显出名字；下方还会展开一条**写给此刻的话**，不是冷冰冰的条件说明
- 已亮的星有缓缓旋转的光环，星位分布是固定坐标，看起来真像一片星座

> 成就总数**故意不显示**。知道终点在哪，探索就没意思了。

星图上目前藏着这些事（都不写在文档里）：

| 星星 | 会因为什么而亮 |
|---|---|
| 第一株 · 渐入佳境 · 半亩方塘 · 殿堂之主 | 图鉴收集进度 |
| 手气不错 · 常客 | 抽签累计到第 10 次 / 第 30 次 |
| 寻珍者 · 不期而至 | 抽中极罕见 / 迎来那次隐藏的保底 |
| 听完了 | 花语墙上的 11 张卡片全部点开过 |
| 完整的 | 六个部门全都看过 |
| 近处 | 在节气转盘上停留满4 秒 |
| 走过四季 | 在三个不同季节的板块停留过 |
| 名有归属 · 署名 | 挑下一个自然名 / 把它正式登记下来 |
| 读完 | 一路滚到最底，又翻了回来 |
| 连星 | 按夜观台给的顺序，点亮三颗星连成一线 |
| 四立之约 · 四时归位 | 按立春→立夏→立秋→立冬的次序轻触 / 集齐四时信物 |

点中的节气会**一直亮着**，画面下方还会报「四立之约 2 / 4 · 下一个：立秋」。
顺序错了才会从头再来，停久了（8 秒）也会重置——但进度看得见，不会以为白点了。
| 不速之客 · 放过 | 遇见那只刺猬 / 选择了让它走 |
| 魔界客 | 走到魔界三位身边各说了一句话 |
| 不留恋 | 走通魔界之后，选了「先走一步」而不是喝完那杯咖啡 |
| 四季的猫 | 春夏秋冬都见过依芽 —— 它也换了四身衣服 |

### 4. 夜观台（隐藏解谜）

星图最底下立着一块长青苔的石台：三个凹槽，各嵌着一枚像素符号，点一下就换一个。
没有计时、没有连点、没有提示按钮 —— 答案就写在页面上，读懂了才打得开。

三句刻痕散落在三个板块的角落，很淡，凑近才看得清：

- 物候图鉴（节气流转）角落：「最先落下的，是天上碎掉的那些」
- 自然图鉴说明旁：「它化了，就趴在草叶上过夜」
- 殿堂铭牌上：「最后亮起来的，不是太阳」

三格对上，石台裂开，点亮第 17 颗星「**夜合**」——它只在夜里开，只开给认真看的人。
解开的状态保存在本机，刷新不会关上；页脚面板有「复位」，成就整体重置也会连带把石台关回去。
> 这些不是「刷多少次」的计数题。每一条都是**你有没有真的看过这个站点**的证据——
> 你看得多，星星就亮得多。

### 依芽（会随季节换装的猫）

右下角那只像素猫叫**依芽**，是这个小世界的向导。点它会说话。

它**跟着季节换装**——页面滚到不同季节的板块，它就换一身：

| 季节 | 装扮 |
|---|---|
| 春 | 头顶一朵小粉花 |
| 夏 | 戴一顶小草帽 |
| 秋 | 顶着一片银杏叶 |
| 冬 | 围着一条红围巾 |

### 短信（有些话没被读到，就一直在等）

左下角有一部像素手机。开场 6 秒后依芽会发来第一条短信，
**它先不替你决定称呼**——它会问你「我该怎么称呼你」，写两个字就行（不想被叫名字也有「不用叫名字」）。

之后每完成一件事，它就再写一封过来：把夜观台转开了、三颗星连成一线、
让那只刺猬走了、推开魔界那扇门……

关掉面板再打开，**已读过的对话会完整回填**，没答完的问题也还在等你。
短信可跟着剧情分支走（有些选项会把你带去别的话题），也会随机抽一批陪聊的话题，话不重样。

### 魔界那扇门（迷阵）

**先把夜观台的连星解开，门才会开。** 连星完成之前，行囊里那行紫字不会出现——
它不是随时能进的地方，是留给走过夜空的人的。

连星之后，行囊面板最底下会出现一行紫字：「通往魔界的那扇门 →」。点开是一片 7×7 的迷阵，
要走到三位魔界生物身边各说一句话。

规则只有一条，很好脾气的规则：**撞墙了不要紧，回到门口再来一次就行**，这里不记仇。
走通了会记下你的最好步数。

走通之后还有一段**茶话**：三位会各说一句，然后给你两个选择——
**留下把咖啡喝完**，或者**先走一步**（会点亮「不留恋」）。两条路都有收获，
这正是这扇门想说的事：不光失败可以重来，走成了也该有个像样的落点。

### 路过的小家伙（偶遇）

不定时的，会有只小生物从屏幕这头走到那头——蝴蝶、蜗牛、麻雀、青蛙、兔子、猫头鹰、
锦鲤、狐狸、鹿都可能来。点它一下，它会说句话。

**不给成就、不占灵树门槛。** 偶遇一旦变成任务就不叫偶遇了，所以行囊里只替你记一笔
「偶遇录：见过几只」。见过的种类会优先排在后面，让「遇见新的」这件事一直成立。

### 放过（有些东西可以不放进行囊）

路上会遇见一只小刺猬。点它，会出现一个选择：**让它走**，或者**收进行囊**。

选哪个都行，不影响你能不能走完全程。
但如果让它走了——你会拿到「放过」这颗光籽，也会收到一封短信。

### 抽签保底机制（隐藏的承诺）

设有一条**保底承诺**：累计抽满 **999 次**仍未遇见，则**第 1000 发必定命中**。

这条承诺**故意不在界面上显示**——没有进度条、没有 `0 / 999`、没有「还差几次」。
页面只留一句模糊的传闻：「据说，运气足够好时……抽得够久，它总会来。」

两条规则：

- **中途自己抽中桂花时，计数不重置。** 也就是说，不管前面有没有抽到过，
  那一千发里的这一发都仍然是你的——运气好不会吃掉你的保底。
- **保底送出后重新起算。**
- **桂花不能被挑走当自然名。** 它是最难的彩蛋：只能被收进图鉴，
  抽到时「挑下」按钮会直接写明「它只进图鉴，不当名字」，自己写名字时输入桂花也会被拦下。
  彩蛋和「你的名字」是两件事，不能同时成立。

达成时会有一场单独的仪式：屏幕中央金光炸开，写上

> 抽到 999 次的时候，桂花自己走了出来。
> 不是运气，是你把它等到了。

同时解锁「不期而至」星星。保底计数存在本地，刷新不清零。

### 自然名：挑一个、写一个、随时换

名字的来路有两条：

- **从抽签机里挑**：抽到的名字里如果有你想要的，点「就选「X」了」把它挑下来。
  没抽到时按钮是灰的——你得先跟这个世界有点关系，才能给它一个名字。
- **自己写一个**：还没入会、还没有自然名？直接写一个，配一句寓意也行。
  写下的名字会**进抽签池**，以后别人也能抽到它。

几条边界都说清楚：

- 协会里**已经有主人的名字挑不走**（会长叫鼠尾草，这名字不能再被登记成「你的」），
  抽到时会直接告诉你「已经有主人了，再抽一个吧」
- **随时反悔**：「换一个名字」一键放下，图鉴第 34 格跟着收回，重新抽或重新写都行
- 挑下的名字成为**图鉴里的第 34 格**（金色边框 + 右角一个「你」字）；若它本来就在
  33 格之内（比如鼠尾草的旧格），则沿用那一格，不重复添加——
  所以图鉴是 33 格还是 34 格，取决于你挑的名字是不是新的
- 也署在殿堂铭牌上

### 数据存储说明

图鉴进度、抽签记录、成就、自然名、兑换码全部保存在浏览器 `localStorage`，
不上传、不联网。**每一项都能单独重置**——页脚有一块「本机进度」面板：

| 项目 | 重置后 |
|---|---|
| 图鉴收集 | 字词全部回到「尚未发现」，你的自然名那一格保留 |
| 抽签记录 | 次数、遇见过的名字清零（隐藏的保底承诺也从头起算） |
| 我的自然名 | 放下名字，图鉴第 34 格一并收回 |
| 成就星图 | 星星全部暗回去，夜观台的石台也会重新合上 |
| 殿堂兑换码 | 圣光收回，兑换码作废；重新集齐后会生成新码 |
| 短信 | 已读过的对话清空，依芽会重新问你怎么称呼它 |
| 魔界门 | 迷阵通关记录和最好步数清零，「不留恋」一并收回 |
| 偶遇录 | 见过的小家伙名单清空，又开始从「没见过的」里挑 |

除了页脚面板，两处还有就地入口：

- 抽签机统计旁的「↺ 把次数清零」——抽过之后才会出现
- 星图下方的「↺ 让这片天重新暗下来」——亮过星之后才会出现

成就重置后**不会因为刷新就自己亮回来**：已经达成过的门槛不算数，
只有你重新跨过一个新的门槛（比如重新收满第一株、再抽满十次）才会重新点亮。

最下面还有「全部重置」：清空本机所有进度并回到初始状态（重置后自动回到页面顶部）。
图鉴区的「清空收集进度」按钮也还在，行为与面板里的图鉴重置一致。

## 技术特点

- **单文件自包含** —— 无构建步骤，改完刷新即可
- **零外链** —— 不依赖任何 CDN 或第三方字体，可离线运行
- **四季主题系统** —— 区块通过 `data-season` 属性驱动整季配色与全局氛围粒子（春瓣 / 夏萤 / 秋叶 / 冬雪）
- **像素风图标** —— 内联 SVG symbol 图标库，会徽与图标统一为像素风格
- **统一滚动调度** —— 多个滚动监听合并为单帧单次执行；页面隐藏时自动暂停无限动画省电
- **响应式** —— 窄屏自动切换为汉堡菜单导航
- **渐进增强** —— JS 异常时仍有兜底逻辑保证内容可见，不会白屏
- **本地存储** —— 抽签记录与图鉴收集进度保存在浏览器 localStorage，刷新不丢
- **图片优化** —— 全部为 progressive JPEG，长边压至 1400px，并标注了尺寸避免加载时布局跳动

### 浏览器兼容

现代浏览器（Chrome / Edge / Firefox / Safari 近两年版本）均可正常运行。

## 图片说明

`assets/` 中的活动照片来源于协会自行拍摄的记录，压缩后长边统一为 1400px、
质量 82 的 progressive JPEG，在保持观感的同时显著减小了体积。

如需替换为更高清的原图，替换时记得同步修改 `index.html` 中对应 `<img>` 标签的
`width` / `height` 属性，以免加载时出现布局跳动。
